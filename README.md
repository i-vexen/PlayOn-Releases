PlayOn 🎵

A modern Android music player with a fluid interface and a focus on the listening experience.

PlayOn is an Android music player designed to bring together local music playback, a clean user experience, and expressive animations inspired by Liquid Glass design.

✨ Features

- Local Music Library – Browse and play music stored on your device.
- Songs, Albums & Artists – Navigate your music collection with dedicated sections.
- Now Playing – A dedicated player interface with playback controls and queue management.
- Shuffle Playback – Enjoy your music in a randomized order.
- Built-in Equalizer – Customize your listening experience.
- Light & Dark Themes – Choose the appearance that suits you.
- In-app Updates – Check for new versions and download available updates.

📥 Download

Download the latest version from the "GitHub Releases" (https://github.com/i-vexen/PlayOn-Releases/releases) page.

🔄 Update System

PlayOn uses a release manifest named "latest.json" to check for available updates.

The manifest contains:

- Current version name and version code
- APK download URL
- SHA-256 checksum
- Release notes

You can find it in the root directory of this repository.
